# Fotos pendientes de iglesias

Las fichas usan una imagen local por templo. Para completar una foto, copia un archivo JPG vertical (proporción recomendada 4:5) a la ruta indicada y ponle el nombre exacto `fachada.jpg`. No necesitas editar código. Si la imagen aún no está, la aplicación muestra el placeholder del proyecto.
